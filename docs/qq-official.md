# QQ 官方 Bot

支持 AstrBot 的 `qq_official` 和 `qq_official_webhook`，复用平台已配置的认证。无需在插件内填 AppID、AppSecret、AstrBot OpenAPI Key，也不需要公网图床。OneBot 保留原有发送方式。

## 抽卡与阅读

抽卡消息将称呼和角色名分成两行引用，再嵌入原有纯角色卡，最后以独立引用显示今日余次／实际额度与按钮：

```markdown
> 狐狸，你今天的盟友是

> Schwarz（NEW）

[卡牌图片]

> 今日剩余3/5 次
```

角色名优先使用中文，无中文时用英文；状态使用 NEW／重复。Bot 配文第一行以“我今天的盟友是”开头，不添加“爱丽丝：”等前缀。收藏进度可通过图鉴查询；首次迁移说明仍独立显示在余次下方。QQ 客户端控制 Markdown 的字体、气泡和按钮外观；插件控制内容、卡牌与操作排列。

开启官方增强后，“查看简介”直接使用 Markdown 阅读：角色名加粗，英文名／编号及首次登场作为引用资料栏，原文按段落留空行，密集长段仅在句末分段。使用内置资料及人工简介，不生成或改写角色描述。取消所有额外的大字号功能标题，保留角色身份信息。关闭增强时继续遵循原来的普通文本／合并转发／简介卡片配置。

- 第一行按钮：再抽一次、我的图鉴。额度用完后隐藏再抽按钮。
- 第二行按钮：角色素材、查看简介、卡比百科。资料按钮绑定当前角色，百科使用真实页面名称，避免把图鉴编号当作另一套百科编号。
- 再抽、个人图鉴及翻页按钮限发起者；角色资料按钮可供同群成员查询。
- `Bot今日盟友`、`Bot盟友图鉴`使用稳定的 Bot 身份与独立次数。
- 素材、内置简介、百科、进度与翻页不会抽取或写入收藏。

猜盟友题目使用小字号提问、来源引用、题图与限时说明，不显示答案名称、编号或角色资料按钮。“开始猜”为指令输入按钮：点击后由 QQ 插入 @Bot 与当前会话前缀对应的 `猜盟友 `，填写中文名或英文名再发送，不自动提交空指令。该按钮对同群成员开放；没有按钮权限、关闭按钮或使用静态模板时，显示完整手动格式（例如 `#猜盟友 <名字>`），引用题目图片直接作答的方式继续保留。

单聊按平台账号和用户生成独立数据范围，与群聊分开。重载后收藏、次数及 Bot 身份保持稳定；已有 OneBot 群数据保留原路径。

支持关联 OneBot 旧 QQ 号与官方 OpenID，或在管理员已关联的旧群中配置按唯一资料昵称自动迁移。绑定后各身份共享旧收藏和次数，换服务器可用配置整包带走；详见[身份迁移](qq-identity-migration.md)。自动匹配要求接口实际提供 `author.username`，不使用群名片或猜测名称。

长简介、百科正文及多张图鉴会分为阅读页，每次请求至多发送一张图片；提供“上一页／下一页”，不依赖 QQ 不支持的合并转发。正文完整保留在有界缓存内，不静默截掉后半段。每份缓存最多 40 万字符、最多保留 64 份阅读会话，20 分钟过期；过期或重载后执行原查询重新获取。翻页同时校验原用户与原会话，不能跨用户或跨群读取。

QQ 增强使用时，发送图片缓存的有效保留时间至少为 21 分钟，以覆盖阅读会话。管理员设定更长保留时间时继续遵循该值。多页图片保留独立快照，后续抽卡或重新生成图鉴不会改变旧阅读页；单份快照最多 256 张、128 MiB。简介仍遵循“盟友简介最大字数”，需要完整阅读时将该配置设为 `0`。

## 配置

位于“QQ 官方 Bot 富文本与按钮”：

| 配置 | 默认 | 用途 |
| --- | --- | --- |
| 启用 QQ 官方 Bot 增强输出 | 开 | Markdown、按钮和阅读分页；关闭则使用 AstrBot 原发送方式 |
| QQ 官方 Bot 抽取默认使用卡牌 | 开 | 将官方 Bot 的文字＋素材升级为精美卡片，沿用卡面主题与随机池 |
| 卡牌在消息中的最大显示宽度（px） | 240 | 与高度一起限制 Markdown 卡牌的展示尺寸，完整等比缩放 |
| 卡牌在消息中的最大显示高度（px） | 420 | 长卡牌同时限制高度，减少聊天刷屏 |
| 其他图片在消息中的最大显示宽度（px） | 480 | 用于猜题、素材、图鉴与百科等非卡牌图片，与高度一起等比缩放 |
| 其他图片在消息中的最大显示高度（px） | 420 | 限制竖图与长图的聊天占用高度，完整显示且不放大小图 |
| Markdown 发送方式 | 原生 Markdown | 也可选已审核模板 |
| Markdown 模板 ID | 空 | 模板模式使用；空值使用原生 Markdown |
| Markdown 模板内容参数名 | `content` | 模板中承载完整内容的参数名 |
| 附加操作按钮 | 开 | 关闭后显示角色与翻页的手动指令 |
| 可选按钮模板 ID | 空 | 使用已有审核模板；空值使用动态指令按钮 |

原来的“卡片＋文字”仍保留完整自定义文案；关闭“抽取默认使用卡牌”后遵循原输出配置。卡牌渲染失败时使用已保存结果的文字与素材，不重新抽取。

两种卡牌输出模式默认完整显示在 240×420 px 范围内，猜题、素材、图鉴及百科等其他 Markdown 图片默认完整显示在 480×420 px 范围内。两组配置分别生效，均同时限制宽度与高度，只等比缩小展示尺寸，不额外缩小或压缩上传图片；点开可放大查看原有细节。普通图片附件的显示大小由 QQ 客户端决定。

模板 Markdown 需提供一个能承载完整内容的参数，例如模板内容为 `{{.content}}`，配置参数名为 `content`。模板的最终处理与图片显示需以已审核模板的实际能力为准。

按钮模板属于静态审核模板，不能由插件动态代入角色编号、用户限制或翻页令牌。使用模板时，正文也会显示本次角色与翻页指令；建议模板提供“今日盟友”“我的盟友图鉴”“盟友帮助”等通用入口。角色精确按钮和按用户限制由动态按钮提供，翻页指令本身始终校验用户与会话。

## 权限与发送回退

官方 Markdown 文档注明：**2026-04-23 起群聊和单聊自定义 Markdown 已向所有机器人开放，频道仍需邀测**。按钮文档的自定义按钮仍标记内邀；Markdown 开放不意味着动态按钮权限同时开放。

动态按钮被明确拒绝时，移除按钮并发送 Markdown＋手动指令；Markdown 也被明确拒绝时，发送普通配文与图片附件。图片素材接口不可用时，改用平台原有附件上传，卡牌与富文本可能分为两条消息。网络超时、服务器错误或无回执属于发送未确认，不自动重发抽卡结果；结果已保存，可按提示编号执行“查盟友”。

本地卡牌使用官方 prepare → COS PUT → complete 三步上传，校验文件大小、格式、MD5、SHA1 和 ETag。预签名图片上传不携带 QQ 认证头或 Cookie。平台最多保留 100 张 Markdown 素材，插件发送后清理自己上传的临时素材；失败记录保留待重试，按 Bot 隔离，不删除其他应用或其他功能的素材。官方说明发送时已转存，删除素材不影响已发送消息。

“今日盟友”“抽盟友”“抽取盟友”支持纯文本触发，无需前缀或 @，仍遵守抽卡白名单。其他命令遵循 AstrBot 当前会话的唤醒前缀：例如配置为 `#` 时，`#卡比真格文本 161` 会进入查询，另一 Bot 使用的 `/卡比真格文档 161` 不会触发本插件。@、引用 Bot 消息及私聊是否可以省略前缀，沿用 AstrBot 的标准唤醒规则。

QQ 官方当前不支持本地 HTML 文件附件，三个百科的显式“文档”指令会直接忽略，不抓取页面、不翻译、不生成文件。需阅读全文时，请使用相应的“卡比百科文本”“卡比F文本”或“卡比真格文本”加页面名；需要 HTML 文件时使用支持附件的 Bot 及其触发前缀。

本版本验证包含本地 SDK 与服务器 SDK 的隔离测试和接口模拟；预览为实际发送内容的示意，未使用真实官方 Bot 账号向群聊发送测试消息。
