# 每日盟友介绍

定时向群友分享一位角色：先发与抽卡相同的纯角色卡，再由 AstrBot 当前会话配置的人格，依据插件保存的真实资料介绍角色，并表达自己的感想。沿用卡比／游戏王主题与随机池；引用卡牌仍可查素材、简介和百科。

此功能有自己的白名单，与普通今日盟友、Bot 手动抽卡分开。它不消耗任何人的抽取次数、不增加收藏，也不显示 NEW／重复或余次。没有真实简介的条目不参与介绍，每群同一天优先介绍不同角色。

在“每日盟友介绍（独立定时与白名单）”中配置：

| 配置 | 默认 | 用途 |
| --- | --- | --- |
| 启用每日盟友介绍 | 关 | 创建／启用独立的 AstrBot 定时唤醒任务 |
| 每日盟友介绍的群会话白名单 | 空 | 完整群 UMO，例如 `default:GroupMessage:932436510`；空名单不介绍 |
| 每日盟友介绍时间 | 12:20、21:05 | 24 小时制，可添加多个时间 |
| 每日盟友介绍时区 | Asia/Shanghai | 决定定时时间及每天记录的日期 |

保存配置并重载插件后更新定时任务。只管理名称以“卡比每日盟友介绍 · ”开头的任务；启用时停用同白名单群中调用旧 Bot 抽卡工具的定时任务，其他定时任务保持原样。关闭功能或移除某群／时间后，相关介绍任务停用；卸载时停用本插件任务。

时间到后使用 AstrBot 原生主代理流程，按目标 UMO 读取会话的人格、模型与工具配置，不在插件中硬编码角色或模型。目标会话必须有可用的聊天模型，并允许使用 `kirby_catalog_daily_ally_intro`；只开放旧的 `kirby_catalog_draw_bot_ally` 时，定时场景兼容转为介绍。手动调用旧抽卡工具仍使用原流程。

介绍记录保存在插件数据目录的 `daily_introductions.json`，与数据目录一起迁移。每群每时段每天最多发送一次，重载不会重复。发送未能确认时保留记录，避免重复发卡；模型或平台不可用时不补发过往时段。角色事实来自内置资料或人工简介，模型的感想是生成内容。
