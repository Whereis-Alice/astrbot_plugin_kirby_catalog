# 今日盟友收藏卡片

[← 返回 README](../README.md)

在插件配置的“抽取与图鉴”中，将“今日盟友输出方式”设为“精美卡片”或“卡片＋文字”，然后选择卡片主题。默认保留“文字＋素材”。

![星愿收藏与银河档案卡面预览](images/daily-ally-preview.jpg)

| 输出方式 | 效果 |
| --- | --- |
| 文字＋素材 | 原来的自定义文案、简介与素材图 |
| 精美卡片 | 一行名称和图鉴编号，随后发送收藏卡片 |
| 卡片＋文字 | 完整自定义文案与收藏卡片 |

同一设置作用于 `今日盟友`、`Bot今日盟友` 和 Bot 抽取工具。卡片外保留“图鉴编号 #编号”，因此引用消息查询百科或简介仍能识别准确条目。

“星愿收藏”使用粉蓝天空、奶油纸面、粉色标题、云朵和金色跃星。“银河档案”使用深蓝星空、粉色标题、星形波普之星和星环。主角素材按原始比例显示；卡片上的中英文名称、首次登场、简介和图鉴编号均来自已有资料。

徽章表达真实抽取结果：初次相遇、再度同行、保底邂逅、今日已相遇或图鉴已集齐。底部显示当前身份的有效收藏数、图鉴总数与今日余次；普通群友和 Bot 分别读取各自的数据。预览中的收藏进度仅为演示数据。

图片在后台线程使用 Pillow 生成，不依赖网页截图服务或大模型。简介和百科提示遵守原有开关，长字段按实际文字宽度换行和截断。卡片小档案优先展示可识别的角色介绍段落；完整原文仍可通过“卡片＋文字”或引用查询阅读。

生成失败会回退到文字与素材，不重新抽取，也不重复扣次数。卡片使用原有发送缓存的保留时间；素材损坏时仍可输出带占位跃星的卡面。

系统需有中文字体：Windows 使用微软雅黑，Linux 推荐 Noto Sans CJK 或文泉驿微米黑，macOS 使用苹方。Debian/Ubuntu 可安装 `fonts-noto-cjk`；缺少中文字体时会回退文字输出。

## 设计参考

- [Nintendo 官方 Kirby 介绍](https://kirby.nintendo.com/about/)：“Pink. Puffy. Powerful.”、Dream Land 和角色介绍。
- [日本官方卡比角色页](https://www.kirby.jp/character/kirby/)：Warp Star、星形 Pop Star 和圆润的云朵。
- [星之卡比官方门户](https://www.kirby.jp/)：粉彩与圆润视觉表达。
- [宝可梦伙伴插件](https://github.com/Whereis-Alice/astrbot_plugin_pokemon_partner)：参考本地 Pillow 卡片与可配置输出的组织方式。

背景、跃星、云朵、波普之星和版式均由本插件绘图代码生成，不打包上述网站的装饰素材。角色素材沿用图鉴原有来源。
