# 今日盟友收藏卡片

[← 返回 README](../README.md)

在插件配置的“抽取与图鉴”中，将“今日盟友输出方式”设为“精美卡片”或“卡片＋文字”，然后选择卡片主题。默认保留“文字＋素材”。

![星愿收藏与银河档案卡面预览](images/daily-ally-preview.jpg)

| 输出方式 | 效果 |
| --- | --- |
| 文字＋素材 | 原来的自定义文案、简介与素材图 |
| 精美卡片 | “狐狸，这是你的今日盟友”等带抽取者昵称的简短提示，随后发送收藏卡片 |
| 卡片＋文字 | 完整自定义文案与收藏卡片 |

同一设置作用于 `今日盟友`、`Bot今日盟友` 和 Bot 抽取工具。精美卡片附上抽取者昵称，Bot 使用“爱丽丝：这是我的今日盟友”等提示；引用卡片回复“素材”可以获取角色素材，回复“查看简介”或“卡比百科”可以继续阅读资料，不消耗抽取次数。

“星愿收藏”以珠光卡纸包边、粉蓝天空、奶油纸面、粉色标题、层叠云朵和烫金跃星构成一页收藏卡。“银河档案”使用极光金属边、深蓝星空、柔和玻璃反光、粉色标题、星形波普之星和星环。两款均由本地程序绘制卡比主题的圆润浮雕、覆膜与资料面板。主角素材按原始比例显示；卡片上的中英文名称、首次登场、简介和图鉴编号均来自已有资料。

徽章表达真实抽取结果：初次相遇、再度同行、保底邂逅、今日已相遇或图鉴已集齐。底部显示当前身份的有效收藏数、图鉴总数与今日余次；普通群友和 Bot 分别读取各自的数据。预览中的收藏进度仅为演示数据。

图片在后台线程使用 Pillow 生成，不依赖网页截图服务或大模型。“今日盟友卡片显示伙伴小档案”默认开启，优先读取管理员人工简介，其次使用内置资料；它独立于消息文字的简介开关。“今日盟友卡片档案最大字数”默认 1000 字，0 使用安全上限 2000 字，也独立于文字长度限制。卡片宽 1024 像素，高度按实际文字在 1640–3000 像素间调整；保留段落，超出最多 40 行的阅读区会明确标记节选。百科提示遵守原有开关，名称、英文名和出处先测量后排版。小档案优先展示可识别的角色介绍段落；原文仍可通过“卡片＋文字”或引用查询阅读。

卡片引用关系保存于插件数据目录的 `card_references.json`，重载后继续有效。消息编号按平台、Bot 和群隔离，图片指纹作为引用图片的补充识别方式；记录最多保留 90 天及 8192 张卡片，之前含编号的盟友消息仍可按文字识别。

“卡片＋文字”和引用“查看简介”仍使用原有的 `ally_description_max_chars` 文字长度设置；需要完整资料时，可将它设为 0。卡面档案使用自己的字数和行数上限。

生成失败会回退到文字与素材，不重新抽取，也不重复扣次数。卡片使用原有发送缓存的保留时间；素材损坏时仍可输出带占位跃星的卡面。

系统需有中文字体：Windows 使用微软雅黑，Linux 推荐 Noto Sans CJK 或文泉驿微米黑，macOS 使用苹方。Debian/Ubuntu 可安装 `fonts-noto-cjk`；缺少中文字体时会回退文字输出。
