# 今日盟友纯角色卡

[← 返回 README](../README.md)

在插件配置的“抽取与图鉴”中，将“今日盟友输出方式”设为“精美卡片”或“卡片＋文字”，然后选择卡片主题。默认保留“文字＋素材”。

![六套纯角色卡的实际渲染预览](images/daily-ally-preview.jpg)

| 输出方式 | 效果 |
| --- | --- |
| 文字＋素材 | 原来的自定义文案、简介与素材图 |
| 精美卡片 | 文字提示、抽取信息与引用说明，随后发送纯角色卡 |
| 卡片＋文字 | 保留完整自定义文案，补充抽取信息与引用说明，随后发送纯角色卡 |

同一设置作用于 `今日盟友`、`Bot今日盟友` 和 Bot 抽取工具。普通用户配文以“狐狸，你今天的盟友是 魔法洛亚（NEW）”开头，Bot 配文直接以“我今天的盟友是 魔法洛亚（NEW）”开头。名称优先使用已有中文，没有中文时使用英文；保留管理员中文改名及 EX 等形态标识。

配文示例（次数和进度仅为演示，实际读取本次抽取结果）：

```text
狐狸，你今天的盟友是 魔法洛亚（NEW）
今日剩余：3/5 次 · 进度：37 / 1,353
可引用本条消息回复：素材、查看简介或卡比百科
```

首次获得标为“NEW”，再次抽到、展示当天已抽到的盟友或图鉴已集齐时标为“重复”。余次以“剩余／当日额度”显示，分母包含管理员增加的机会，并与抽取结果一起保存快照；普通群友与 Bot 分别读取各自的数据。两种卡牌模式只显示一行引用命令列表，不再额外追加自定义百科提示；关闭百科提示开关后，该行只列出“素材或查看简介”。“卡片＋文字”保留原有主体文案与余次格式，将自动附带的百科提示合并为同一行命令列表。

## 卡面内容与主题

图片展示角色名称、英文名、图鉴编号、大幅立绘、首次登场与“简介”。名称相同的中英文不重复显示；缺少出处或简介时隐藏对应内容。游戏王套系另有统一的星字圆章和随机星级。今日盟友标题、日期、收藏者、品牌水印、抽取状态、余次、收藏进度与操作说明均不放入卡面。

| 卡面 | 构图与材质 |
| --- | --- |
| 星愿收藏 | 珠光包边、粉紫浅蓝纸面、压印星纹与层叠云朵，简介使用同色系柔和底纹 |
| 银河档案 | 极光包边、深蓝星云、弧形细纹与星形波普之星，简介延续深蓝纹理 |
| 梦泉琉璃 | 金色拼接线和彩色琉璃拱窗，立绘下方放置角色铭牌，青绿磨砂底板承载简介 |
| 毛线物语 | 织纹、拼布边缘、缝线标题与纽扣，椭圆织物展示区和暖粉布袋式简介 |
| 波普漫画 | 网点、放射线、倾斜画框与红色标题带，暖色对话框承载简介 |
| 星海航记 | 星图网格、环形刻度与航线、黄铜标题铭牌，以票券虚线连接浅青航记区域 |

六套卡面在构图、装饰和阅读区上分别设计，纹理均由本地程序确定性绘制；简介底板降低纹样对比，保证文字清楚。没有额外图片服务依赖，角色素材沿用图鉴现有资料。

### 两套随机模式

| 模式 | 随机范围 |
| --- | --- |
| 卡比卡面随机 | 原有六款卡比卡面；可在“卡比卡面随机池”中多选 |
| 游戏王卡面随机 | 同一套游戏王模板的五种印刷卡纸；星级独立随机 |

将“今日盟友卡片主题”（`ally_draw_card_theme`）设为其中一种模式并保存，即可使用。两套各自随机，不混合选择。旧“随机主题（自动）”“随机”“自动”值继续按卡比随机解析；原有固定卡比主题仍可选择。新配置默认采用卡比随机，输出方式仍默认文字＋素材。

卡比随机默认六款全部参与，每次独立、等概率选择，可能连续出现同一卡面。只选一款时固定使用该款；留空或全部配置无效时使用全部六款，重复配置项不会增加权重。固定主题与游戏王模式忽略这个列表。

### 游戏王卡面套系

![游戏王套系五种卡纸的实际渲染预览](images/yugioh-ally-preview.jpg)

沿用用户提供的游戏王模板，保留 1080×1680 的实体卡比例、厚框阴影、云纹卡纸、星级圆球及金色／虹彩印字。五种卡纸为云纹铜棕、玫红珠光、紫银微闪、黑金箔面、银白虹彩，每种被选中的概率相同。1–12 星独立等概率随机，与角色、卡纸、图鉴进度无关。

排版适配图鉴资料：上方完整卡名与统一星字圆章，中央大幅立绘，画窗下显示英文名，信息纸显示“简介”，卡底左侧显示首次登场作品，右下角显示图鉴编号。简介最多十行节选，超出阅读区用省略号标明；引用“查看简介”可继续读取资料。缺少简介时隐藏标签和正文，出处或英文名缺失时省略相应字段。

内置角色的 1342 个不同名称备有整词／整句隶书图像；少量隶书未覆盖的名称整句使用宋体。过长名称和管理员自定义名称使用随包字体完整排版，可分两行。卡面只使用实际名称、立绘和简介，星级与卡纸仅作为印刷外观。

自动挡同时用于普通用户、`Bot今日盟友` 和 Bot 抽取工具。它只决定已抽取角色的展示样式，不改变抽取概率、收藏、次数或引用查询；再次展示当天已抽到的角色时，也可能换用另一套卡面。

立绘先裁除透明或可识别的白色空边，再按比例填入更大的展示区，允许小素材放大，但不拉伸或裁切角色。小尺寸有限色像素图保留像素边缘，其他图片平滑缩放；低分辨率原图放大后仍受自身清晰度限制。此处理仅作用于卡面副本，不修改原素材。动态素材在卡面使用首帧，引用回复“素材”仍按原有发送设置提供该角色素材，保留支持的 GIF 动画。

## 简介与长度设置

“今日盟友卡片显示简介”默认开启，优先读取管理员人工简介，其次使用插件内置资料，不调用大模型编写角色介绍。它独立于消息文字的 `ally_description_enabled` 开关；关闭文字简介仍可显示卡面简介。关闭卡面开关或没有资料时，隐藏简介区域。

“今日盟友卡片简介最大字数”（`ally_draw_card_description_max_chars`）默认 1000 字，0 使用安全上限 2000 字。卡比卡面宽 1024 像素，高度按实际内容在 1440–3000 像素间调整，简介最多 40 行；游戏王卡面保留 1080×1680 的固定实体卡比例，简介最多十行。保留段落和英文单词，超出字数或阅读区的内容以省略号标明节选。原文有开篇引用时，优先展示可识别的角色介绍段落。

“卡片＋文字”和引用“查看简介”仍使用原有的 `ally_description_max_chars` 文字长度设置，需要完整资料时可将它设为 0。卡面简介使用自己的字数和行数上限。

## 引用查询与兼容性

引用卡片回复“素材”获取角色素材，回复“查看简介”读取资料，回复“卡比百科”继续查询百科；这些操作不重新抽取，不写入收藏，也不消耗次数。

卡片引用关系保存在插件数据目录的 `card_references.json`，重载后继续有效。消息编号按平台、Bot 和群隔离，图片指纹作为引用图片的补充识别方式；记录最多保留 90 天及 8192 张卡片，之前含编号的盟友消息仍可按文字识别。

图片在后台线程使用 Pillow 生成，不依赖网页截图服务或大模型。抽取结果先保存，再绘制卡片；生成失败会回退到文字与素材，不重新抽取，也不重复扣次数。卡片使用原有发送缓存的保留时间；素材损坏时仍可输出带星形占位图的卡面。

游戏王套系使用随包字体和完整名称图像，Linux 也能保持相同的印刷字体。卡比套系需系统中文字体：Windows 使用微软雅黑，Linux 推荐 Noto Sans CJK 或文泉驿微米黑，macOS 使用苹方。Debian/Ubuntu 可安装 `fonts-noto-cjk`；缺少中文字体时会回退文字输出。
