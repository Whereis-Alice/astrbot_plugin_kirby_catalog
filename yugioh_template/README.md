# 游戏王卡面组件（卡比接入版）

来源为用户提供的 `yugioh-card-template.zip`，保留五种印刷底纹、实体框边、星级圆球、覆膜光线与金色／虹彩卡名。单卡为 1080×1680。

本插件在 `ally_yugioh_card.py` 映射真实图鉴资料：名称、英文名、编号、立绘、首次登场和简介。图鉴编号位于卡底右下角，与左侧首次登场信息对齐。`星` 圆章作为统一主题标志；卡纸和 1–12 星独立随机，仅用于外观。简介最多十行节选，其他字段不填充虚构属性或攻防。

卡比内置名称使用整词／整句的隶书图像遮罩，替换模板示例名称；过长名称和未知名称使用随包中文字体完整排版，可分两行。正文与辅助粗体保留 Noto Serif SC 的字形和字重，扩充至图鉴实际字符集。完整名称遮罩不提供单字重组接口，也不包含 Windows 字体文件。

本组件的 Python 代码使用 [MIT](LICENSE)；字体许可与版权保存在 `assets/fonts/OFL-*.txt` 和字体元数据中。底纹、框边与光线沿用用户模板的参考素材，第三方美术权益归原权利人。

相较原模板，增加 `RenderOptions.description_max_lines`（默认 7），由卡比接入设为 10，并保留英文单词和段落换行；版面尺寸与材质不变。Pillow 为运行依赖，fontTools 仅用于开发期字体准备。
