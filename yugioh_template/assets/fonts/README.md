# 模板字库

正文使用 Noto Serif SC 500，标题辅助与纯黑粗体使用 Noto Serif SC 800。自定义名称可使用 title_font_path 或整行 TitleArtwork；预制 1342 个卡比完整名称图像，隶书未覆盖的少量名称整句使用宋体，不拼接单字。

PartnerDuelKai-Regular.ttf 为霞鹜文楷子集，用于未预制名称的回退。超出姓名子集的文字会整行回退到 Noto Serif SC。正文包含 GB2312、ASCII、卡比内置资料实际用字及所用标点；更广字符集可由调用者提供字体。

PartnerDuelSymbols-Regular.ttf 为 18 个属性单字和问号的独立子集。自定义属性章改用正文字符集或指定的 font_path，不用这个有限子集代替任意新字。

字体均使用 SIL Open Font License 1.1，修改后的字体族名为 Kirby Card Serif、Partner Duel Kai 与 Partner Duel Symbols。原版权信息保留在 TTF 元数据及同目录的两份 OFL 许可文件中。
